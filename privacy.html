Privacy Policy

Luke Control Deck is a local desktop control application for Windows.

Data collection

Luke Control Deck does not collect, sell, share, or transmit personal data.

Local storage

The application may store configuration files, button settings, cached icons, and integration settings locally on the user's computer.

Voicemod integration

If Voicemod integration is enabled, Luke Control Deck communicates only with the locally running Voicemod desktop application through Voicemod's local Control API. Luke Control Deck does not record, process, upload, or store voice audio.

Contact

For questions about this privacy policy, contact the project owner through GitHub.
